## Project Overview

Finance Tracker is a modern full-stack web application designed for intuitive personal expense and income tracking. Built with Python, Flask, and SQLite, it offers real-time cash flow visualizations and custom theme customization.

## Key Features

- **Dynamic Cash Flow Breakdown**: Interactive Chart.js doughnut visualization mapping income vs. expense distribution with real-time theme synchronization.
- **Multi-Theme Engine**: Built-in OLED Dark, Light Mode, and Forest Dark themes with saved local storage preference.
- **Transaction Management**: Add, edit, filter by category (Income/Expense), and track transactions seamlessly.
- **KPI Summary Cards**: Real-time net balance, total income, and total expense indicators with custom indicators.
- **Responsive & Modern UI**: Built with custom CSS design tokens, Fira Sans & Fira Code typography, and Lucide icons.

## Technical Details

- **Backend**: Python 3 with Flask framework and SQLite database (`transactions.db`).
- **Frontend**: Vanilla HTML5/CSS3 with CSS custom properties for theme system.
- **Visualization**: Chart.js for data visualization, auto-adapting to CSS design system tokens.
